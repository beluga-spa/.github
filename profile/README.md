## 💡 O Problema

> O estudante universitário usa **5, 6, 7 aplicativos diferentes** para organizar sua vida acadêmica.  
> Um para notas. Um para tarefas. Um para estudar. Um para tirar dúvidas. Um para acompanhar o desempenho.  
>  
> **Isso precisa acabar.**

---

## 🚀 O que é o BELUGA?

O **BELUGA** é uma plataforma acadêmica inteligente desenvolvida como **Single Page Application**, projetada para ser o ambiente central da vida universitária.

Em uma única experiência, o estudante encontra tudo que precisa:

| 📚 | Plano de estudos personalizado |
|----|-------------------------------|
| 🧠 | Quizzes e reforço de conteúdo |
| 📊 | Acompanhamento de desempenho em tempo real |
| 🤝 | Feed acadêmico e fórum de discussão |
| 🏆 | Gamificação com XP, níveis e conquistas |
| 🤖 | **Belugin-IA** — assistente acadêmica inteligente |

## 🤖 Belugin-IA

A **Belugin-IA** é a assistente acadêmica do BELUGA — disponível em todas as telas, pronta para ajudar o estudante com recomendações, resumos e acompanhamento de progresso.

> *Interface funcional com arquitetura preparada para integração com modelos de linguagem (GPT-4 / OpenAI API).*
